Write a program that reports on these exam scores:

- Ada: 92, 88, 95
- Linus: 75, 64, 81
- Grace: 85, 91, 79
- Alan: 58, 62, 49

Use a data class for a student. Print each student's average (with one decimal) and letter
grade, highest average first. The grade is A for an average of 90 or more, B for 80 or more, C
for 70 or more, D for 60 or more, and F otherwise. Then print the average of the four averages
and, in alphabetical order, the students who passed (an average of 60 or more).

The program must print exactly:

```
Ada: 91.7 (A)
Grace: 85.0 (B)
Linus: 73.3 (C)
Alan: 56.3 (F)
class average: 76.6
passed: Ada, Grace, Linus
```
