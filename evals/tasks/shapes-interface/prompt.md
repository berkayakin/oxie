Define an interface `Shape` with the methods `name()` and `area()`, and a default method
`describe()` that returns the name and the area with two decimals, like
`circle with area 3.14`. Implement it in three classes: `Circle(radius)`,
`Rectangle(width, height)` and `Triangle(base, height)`.

Put a circle of radius 1.5, a 2 by 3.5 rectangle and a triangle with base 4 and height 2.5 in
one list, sort the list by area (smallest first), print each shape's description, and then the
total area with two decimals.

The program must print exactly:

```
triangle with area 5.00
rectangle with area 7.00
circle with area 7.07
total area: 19.07
```
